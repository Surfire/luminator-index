# 可选文本语义搜索（2026-10-13）

已接入 Tinycast 本地主搜索体验版。名称、正文关键词和语义各有独立查询通道；
名称先显示，语义等待输入稳定 250 ms 后补充，按路径去重，结果标记“语义相近”。
Enter 打开原文件；不生成答案，不处理图片、音频、视频或 OCR。

## 控制与范围

Settings → File Search → Luminator → Semantic text search 默认关闭。
开启正文后，可选一个已有正文权限的目录和已下载的 EmbeddingGemma 2 Q8_0 文件。
首版只允许一个语义目录，避免多根重复加载模型；名称仍支持多目录。
“暂停语义建库”保留已有搜索结果；恢复或重启后按已落盘的进度继续。
关闭语义会终止服务及模型进程，保留索引。暂停状态和模型/目录选择由本机设置保存。
模型权重不随应用分发，应用包含独立的 Metal 文本推理 helper。

```sh
luminator --db /local/names.semantic.sqlite semantic \
  --content-db /local/names.content.sqlite --helper /local/LuminatorTextEmbedder \
  --model /local/embeddinggemma-2-Q8_0.gguf --socket /tmp/semantic.sock --enable
# 加 --paused 可仅搜索已建部分。关闭进程用 SIGTERM。
```

Unix socket 接收 JSONL：`{"query":"描述要找的内容","limit":20}`；
`{"paused":true}` / `{"paused":false}` 控制建库，`{}` 返回进度和错误。
查询 `mode:"semantic"` 可用于纯向量对照；默认融合向量和现有中文双字全文的 RRF 排名。
查询级最高余弦不足 0.74 时不返回结果；阈值是开发集上的保守选择，不能解释为正确率。

## 数据与资源

- 只读正文库，不重新打开源文件正文；编码前和返回结果前检查文件指纹及云占位标志。
  内容提取和 CLI 均启用内核禁止自动物化云文件策略。云端文件不触发下载。
- 独立 SQLite WAL 数据库、0600 权限；绑定内容库和模型 SHA256、前缀/维数版本。
  768 维 float32；不混用模型空间。更改模型/维数需要另一份索引。
- 每段提交保存进度；过期/删除的结果立即由源指纹过滤，后台清理旧向量。
  有限队列一次读取最多 32 段，新片段优先，最多十秒刷新队列；源文件变化后仍需先完成正文提取。
- 单个模型进程、每次编码一段，CPU 线程四个，后台优先级；每次工作后让出约三倍处理时间
  （30–500 ms），并优先响应查询。持续查询也会定期留出后台推进机会。
- 模型闲置 30 秒退出；暂停时仍可按需加载查询。超过 worker 的 2048 token 限额会计为失败，
  不静默截断。UI 显示失败段数。首版未做并行 GPU 批量编码、段落内容哈希去重或 ANN。
- 模型错误只影响语义通道；索引可以边建边搜，但完成前覆盖不全。

## 验证与边界

真实目录的固定开发集：50 条中文改写查询，预先指定目标文件；20 条无关主题对照。
在已完成 **17,389 / 92,478 段**的相同快照上：

| 查询方式 | 目标文件进入前 5 | 进入前 20 | 查询往返 p95 |
| --- | --- | --- | --- |
| 纯向量 | 31/50 | 36/50 | 15.3 ms |
| 全文与向量融合 | 34/50 | 43/50 | 69.7 ms |

20 条无关主题在该快照和阈值下无结果。它们参与了阈值选择，不是独立验收集。
这些查询主要验证资料导航和同义表述，不能代表完整资料库的最终召回率。
另一轮候选较少时的 44/50 不可与此表直接比较。正式质量目标尚未达到，排序仍需改进。

名称通道在四轮交错测试中，每轮 200 次、五库并行：暂停建库 p95 为 3.60 / 3.98 ms，
后台建库为 3.54 / 3.93 ms；建库期间每轮新增 73 / 75 段，暂停两轮均不增长。
这是 socket 往返，不含 UI 和用户输入等待；不宣称所有机器或满库同样快。

`scripts/check-semantic.py` 用真实模型和隔离的合成文档验证：6 条同义查询首位命中、
暂停仍可搜索、新增在恢复后补建、退出重启续建、修改/重命名/删除、正文未重扫时立即过滤旧结果。
Swift 测试覆盖解码、语义标记、暂停进度、过期查询、设置保存及权限不随备份导入。
Debug/Release 构建、Rust 测试及 clippy 通过。界面不做抢焦点的自动化；安装后通过 app 自管服务验证。

公开结果只含聚合统计；原文、文件名、向量和查询明细保留在用户本地私有证据目录。

安装后再次通过实际 app 自管 socket 返回语义结果；无窗口 Swift 协调器探针验证了
暂停启动、查询、暂停期间新增、恢复续建、关闭语义不影响名称、重新开启保留进度。
安装前后枚举到的 819 个云占位文件中，转为本地文件为 0。
期间目录有 38 个新增文件、3 个原有文件大小或修改时间变化，说明源目录并非静止快照；
本任务的索引与推理代码不写源正文，不能把这些外部变化算作我们的增量验收样本。
