# 阶段 1：Rust 文件名索引引擎与 CLI

日期：2026-10-12。已完成本阶段实现与本机合成数据验证；Tinycast、Raycast、正文解析和模型未接入。以下只描述名称阶段，不代表完整 v0.1 已完成。

本文保留当日版本的实测和限制；2026-10-13 的多音字、排序、并行查询及实时更新优化见 [后续报告](filename-optimization.md)。下文单字拼音与 `--under` 限制属于旧版本。

## 可运行的能力

- Rust 管理紧凑 SoA 名称索引、父节点、Top-K、筛选、SQLite 编目和 CLI / Unix socket 服务。
- 直接复用固定版本 Oil Find 的 C 批量目录扫描、NEON 子串匹配及匹配质量算法；源码保持原样，版权与 MIT 文本保留。拼音借鉴其系统转写表方法，由 Rust 管理全拼/首字母键，小型 C 桥调用 CoreFoundation。
- 中文名称中间子串、拼音全拼/首字母、英文大小写、Unicode NFC/NFD、完整路径子串，以及类型/扩展名/目录筛选。
- FSEvents 更新新增、改名、移动、删除和大小/秒级时间元数据；保存事件游标与卷 UUID，恢复停止期间的变更。丢事件标志触发完整补扫。
- 每库一个目录、单写入者；CLI 可读取保存快照，也可请求前台常驻服务。不自动扫描资料、不注册后台服务。

未复制 DigUp 或 Tinycast 源码；正文与模型工作留给后续阶段。第三方实际来源见 [notices](../THIRD_PARTY_NOTICES.md)。

## 数据和计时口径

测试源代码提交与环境详见 [environment.json](../benchmarks/results/2026-10-12-m5-max/environment.json)。机器为 Apple M5 Max / 128 GB MacBook Pro，macOS 27.0.1 (26A434)，arm64 Release，Rust 1.96.0；接电，AC powermode=2，内部 APFS 卷约 658 GiB 可用。

使用 `fixture` 在磁盘上实际创建 **1,000,000 条**：1,000 个目录、999,000 个空文件，扫描包含根目录共 1,001 个目录。文件名中 199,000 条为中文、50,000 条为 NFD 拉丁名称，其余为 ASCII；混合 PDF/DOCX/MD/TXT/JSON/ZIP 后缀，文件正文为空。数据树创建耗时约 47.94 秒，**不计入建库时间**。

这是浅目录合成集，不包含深路径、超长名称、实际文档内容或云占位。原始名/规范化名/全拼/首字母合计名称池 31,482,000 字节，SQLite 主库 123,183,104 字节（约 117.48 MiB；不含活动 WAL）。根节点不计入百万条目，但占用一个索引 slot。

未清除系统缓存，目录创建及此前测量已使文件系统缓存变热；恢复为新进程读取已有库，不能称作冷盘测试。每条查询预热一次后重复 20 次，Top-K=20。普通 50 条查询共 1,000 样本，含中文、拼音、大小写、NFD、编号、后缀及未命中；另列 5 条高命中查询共 100 样本、1 条路径查询共 20 样本。p95 使用最近秩法，保留所有样本。

引擎计时包含查询规范化、候选匹配、排序、Top-K 与路径构造，排除数据库恢复和进程启动。socket 计时使用 Python 客户端，包含连接、JSON 请求、后台处理和回复解析；不包含每次运行 CLI 子进程的开销。

## 正确性与开发检查

`cargo test --locked`：4 项集成测试通过，0 失败。覆盖中文中间词、全拼/首字母、NFC/NFD、大小写和筛选；超过 300 个候选时仍选出最佳结果；路径子串结果与完整路径逐条匹配结果一致；SQLite 重载、目录改名/移动、同名替换、硬链接、删除、符号链接不跟随；真实 FSEvents 更新及停止期间恢复；多个写入者冲突；分段写入 JSON 请求。

`cargo fmt --check`、`cargo clippy --all-targets --locked -- -D warnings`、`cargo build --release --locked` 均通过。vendor C/header/license 与固定上游 checkout 逐字节一致；三个上游工作区没有改动。

测量过程中发现并修复两个实际瓶颈：按每个文件重建路径导致路径查询约 863 ms，改为按不同父目录构造；C 辅助函数跨编译单元调用拖慢名称扫描，合并编译单元后可内联，vendor 源码保持原样。最终结果以表格和原始记录为准，不混用早期数据。

## 复现和当前限制

编译、普通查询与完整 benchmark 命令见 [README](../README.md)。本机保留的合成树及数据库位于 `benchmarks/local-results/`，已被 Git 忽略；不会将百万空文件、索引或本机日志提交。

- 仅 macOS，实测为 Apple Silicon。每库单根目录；尚无多根配置、暂停/恢复配置接口、安装包或登录服务。
- 查询当前为 O(N) 全候选匹配，不缓存前一轮 Top-K；路径查询按父节点去重。`--under` 在候选过滤时构建路径，尚未单独做百万条目性能验收。
- 拼音使用常用汉字单字读音，无法消歧多音字；不处理拼音声调、AND/OR 或正则语法。
- 更新与查询使用同一循环，大型补扫可能阻塞查询；全补扫并发延迟、事件丢失强制恢复、根目录移动/卸载、崩溃中断尚未做故障场景验收。
- 高频长期删除会留下 tombstone，改名会留下旧名称池；重启会重建紧凑名称池，但尚未在线压缩 tombstone。增量后预留数组容量与实际物理内存分别报告。
- 时间戳精度为秒；同秒内等大小内容修改不保证被区分。inode 复用不等于内容身份相同，未来正文阶段仍须实现 generation 校验。
- 不跟随符号链接，不读取文件正文，不向 dataless 目录下降；非 UTF-8/不支持类型或枚举错误计入 skipped。真实 OneDrive/iCloud 覆盖、Spotlight 补充、深/长路径和长名压力为 NOT_RUN。
- Oil Find 同集性能对照、DigUp、全文、语义和两个宿主 UI 均为 NOT_RUN。不能据此宣称超过 Oil Find、替代 Spotlight 或已经兼容 Raycast。

下一阶段建议先用一个明确选定的本地小目录体验 CLI 和增量行为，再决定正文提取范围；保持 Tinycast 和模型接入分阶段推进。
